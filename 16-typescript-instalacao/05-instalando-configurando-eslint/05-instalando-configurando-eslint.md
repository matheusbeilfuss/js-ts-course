# Instalando e configurando o ESLint

- `npm i eslint -D`
- `npm i @typescript-eslint/eslint-plugin @typescript-eslint/parser -D`
- Criar o arquivo `.eslintrc.js`
  - Atualmente, o nome do arquivo deve ser `eslint.config.js
  - Outras modificações foram feitas para atender ao padrão atual
    - Uma delas foi a instalação do globals: `npm i globals -D`
