# Tipos null e undefined

- Ambos representam "não valor", mas a intenção de uso deles é diferente.
- Undefined: indefinido. Quando algo ainda não foi definido ou pode ser indefinido.
- null: nulo. Quando há um motivo para retornar um valor nulo explicitamente.
  - Comum quando ocorre algum erro. Retornar null quando não encontra algo no BD, por exemplo.
