# O Structural type system do TypeScript

- TS usa um sistema de tipos chamado "structural typing".
- Para o TS, a identidade do tipo não importa muito, somente as restrições que estão naquele tipo.
- Não necessariamente um tipo passado precisa ser o esperado, apenas ter as mesmas restrições que o tipo esperado tem.
- TS se preocupa com o conteúdo dos tipos, não com o nome deles.
